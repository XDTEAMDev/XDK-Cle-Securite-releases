# XDK Clé Sécurité — téléchargements

Logiciel Windows (10 et 11) de **XDK TEAM DEV** pour **protéger tous tes comptes avec une clé de sécurité USB**
(YubiKey ou autre clé FIDO2), un compte après l'autre, et **retrouver tes vieux comptes oubliés**.

Le logiciel **ne voit jamais tes mots de passe ni tes comptes** : il ouvre la bonne page de chaque site dans ton
navigateur, t'explique quoi faire, et retient ce qui est fait, seulement sur ton PC.

## Télécharger

1. Ouvre la [dernière version](https://github.com/XDTEAMDev/XDK-Cle-Securite-releases/releases/latest).
2. Télécharge **`XDKCleSecurite.exe`** (le fichier `.sig` à côté sert seulement à vérifier les mises à jour).
3. Lance-le.

Il faut le **.NET 8 Desktop Runtime** (x64), gratuit chez Microsoft : https://dotnet.microsoft.com/download/dotnet/8.0
(« .NET Desktop Runtime »).

## Clé (essai gratuit de 24 h)

Il faut une **clé** pour utiliser le logiciel :

1. Ouvre le logiciel : il affiche le **code de ton PC** (par exemple `ABCD-EFGH-JKLM`). Copie-le.
2. Rejoins le **Discord XDK TEAM DEV** : https://discord.gg/zEC35KSuxt, choisis ta langue, puis va dans la catégorie
   🔐 XDK CLÉ SÉCURITÉ, salon 🔑・demande-de-clé.
3. Clique sur « Essai gratuit » et colle ton code PC : le bot t'envoie ta clé tout de suite en **message privé**.
4. Colle la clé dans le logiciel et clique sur « Activer ».

Une clé ne marche que sur le PC de son code.

## Ce qu'il fait

- **1 clic par compte** : chaque bouton ouvre directement la page où ajouter ta clé USB (Google, Microsoft, Discord,
  Facebook, Roblox, GitHub, Amazon, PlayStation, X…), avec les étapes expliquées et dans le bon ordre : code PIN de la
  clé, plan B si tu la perds, ta boîte mail d'abord (elle sert à récupérer tous les autres comptes).
- Pour les sites qui n'acceptent pas encore les clés USB (Instagram, TikTok, Snapchat, Twitch, PayPal, Epic Games…) :
  la double protection par appli d'authentification.
- **Retrouver tes comptes oubliés** : les sites où tu te connectes avec Google, tes mots de passe enregistrés et ceux qui
  ont fuité, tes vieux mails d'inscription, les fuites de données, et comment fermer les comptes qui ne te servent plus.
- Tes propres comptes en plus (« + Ajouter un compte »), barre de progression, bouton « Suivant ».
- Voit quand ta clé USB est branchée.

## Mises à jour

Automatiques : à chaque lancement, le logiciel regarde ici s'il existe une nouvelle version, la télécharge, vérifie sa
**signature** et redémarre dessus. Un fichier qui n'est pas signé par XDK TEAM DEV est refusé.
